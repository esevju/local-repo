# Windows Server Study Materials

## Overview

Windows Server is the enterprise-grade operating system powering data centers and providing core directory, identity, and infrastructure services. This includes Active Directory, file sharing, print services, and application hosting.

## Topics

### Windows Server Fundamentals
- Server editions and features
- Installation and configuration
- Server roles and features
- Server Manager and administration
- PowerShell for automation

### Active Directory & Identity Services
- Active Directory structure
- Organizational Units (OUs)
- Users and Accounts
- Security Groups and Distribution Groups
- Group Policy (GPO)

### User & Account Management
- Creating and managing user accounts
- Account policies and security
- Password policies
- Permission delegation
- Account lockout and auditing

### Group & Access Management
- Security groups
- Distribution groups
- Group membership and nesting
- Access control and permissions
- Delegation of administration

### Storage & File Services
- File Server role
- NTFS permissions
- File sharing (SMB)
- Storage Spaces
- Backup and disaster recovery

### Network & Communication Services
- DHCP server
- DNS server
- Routing and Remote Access
- VPN services
- Network access protection

### Security & Compliance
- Security policies
- Auditing and logging
- BitLocker and encryption
- Windows Defender for Server
- Security baselines
- Compliance requirements

## Study Approach

1. Master Windows Server fundamentals
2. Understand Active Directory architecture
3. Study organizational structure (OUs, Groups)
4. Learn user and account management
5. Explore network and storage services
6. Review security policies and compliance

## Key Concepts to Master

- Active Directory structure and design
- Organizational Units and GPO
- User accounts, groups, and permissions
- NTFS and file sharing
- Group Policy application
- Security policies and access control
- Delegation and delegation models
