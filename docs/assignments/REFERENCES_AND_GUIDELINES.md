# Assignment References & Guidelines

## How to Use This Assignment

This assignment is designed to help you document a complete IT infrastructure solution covering enterprise systems, network design, security, and operations.

### Structure

The assignment is organized into 10 main sections:

1. **Network Design** – Planning and designing the network infrastructure
2. **Hardware** – Selecting and specifying server, client, and network hardware
3. **Organizational Units (OUs)** – Designing Active Directory structure
4. **Groups** – Planning and implementing group management strategy
5. **Users and Accounts** – Managing user accounts and identities
6. **Storage** – Designing file storage, sharing, and protection
7. **Policies** – Implementing password and security policies
8. **Security** – Addressing physical, software, and web security
9. **Solution** – Integrating everything into a coherent solution
10. **Management** – Implementing operational management and support

### Using the Templates

- Copy the template for each section

Use `docs/assignments/templates/research-template.md` for topics that need deeper investigation:

### Writing Guidelines

#### Structure & Organization
- Use consistent heading hierarchy
- Number sections and subsections clearly
- Include section summaries
- Add table of contents links

#### Content Quality
- Write in clear, professional language
- Avoid jargon or explain technical terms
- Use examples to illustrate concepts
- Include diagrams and tables where helpful
- Reference authoritative sources

#### Practical Focus
- Include implementation steps
- Provide configuration examples
- Address common challenges
- Explain best practices
- Discuss scalability and enterprise considerations

#### Linking & Cross-References
- Link related sections within the document
- Reference study materials from `docs/` folders
- Cite external sources and Microsoft documentation
- Connect theory to practice

### Tips for Success

1. **Start with outline** – Use ASSIGNMENT_OUTLINE.md as your starting point
2. **Research as you write** – Use research template for deeper topics
3. **Use real-world examples** – Draw from your studies or professional experience
4. **Be specific** – Provide concrete details rather than general statements
5. **Consider enterprise scale** – Think about large organizations, not just small businesses
6. **Link concepts** – Show how different sections relate to each other
7. **Include visuals** – Use diagrams for architecture and complex relationships
8. **Reference standards** – Include Microsoft best practices and industry standards
9. **Proofread carefully** – Review for clarity and accuracy
10. **Update as you learn** – Add new insights as your understanding grows

### Expected Content Depth

- **Each main section:** 2-4 pages of detailed content
- **Total assignment length:** 25-40 pages (including examples and diagrams)
- **Sections should include:** Concepts, implementation, examples, and best practices
- **Format:** Professional document suitable for presentation or submission

### Recommended Writing Order

1. Start with **Network Design** (foundation)
2. Move to **Hardware** (implementation)
3. Build **Active Directory** sections (OUs, Groups, Users)
4. Add **Storage** and **Policies**
5. Integrate **Security** considerations throughout
6. Write **Solution** overview (tie everything together)
7. Detail **Management** procedures
8. Create introduction and conclusion
9. Add diagrams and visuals
10. Final review and polish
