# Windows-klient studiemateriale

## Oversikt

Windows-klient omfatter skrivebords- og bærbare operativsystemer designet for sluttbrukere. Moderne Windows inkluderer skrivebordsstyring, sikkerhetsfunksjoner, GroupPolicy-applikasjon og bedriftsdeploying-funksjoner.

## Emner

### Windows operativsystem grunnleggende
- Windows-versjoner og utgaver
- Installasjon og distribusjon
- Filsystemer (NTFS, ReFS)
- Register og systemkonfigurasjon
- Brukergrensesnitt og navigasjon

### Brukerstyring og autentisering
- Lokale brukerkontoer
- Passordretningslinjer
- Brukerprofiler og tillatelser
- Brukerkontokontroll (UAC)
- Legitimasjonsstyring

### Systemadministrasjon
- Enhetsstyring
- Driverstyring
- Programvareinstallasjon og konfigurasjon
- Windows-oppdateringer og oppdatering
- Ytelsesovervåking

### Windows-funksjoner og tjenester
- Windows Defender og antivirus
- Brannmurkonfigurasjon
- Fjerntilgang (RDP, VPN)
- Virtualisering (Hyper-V)
- Fildeling og tillatelser

### Bedriftsstyring
- GroupPolicy (GPO) applikasjon
- Domenetilkobling
- Enhetssamsvar
- Mobil enhetsstyring (MDM)
- Skytilknytning til identitet

### Sikkerhet
- Bitlocker og kryptering
- Windows Defender for Endpoint
- Sikkerhetsbasislinjer
- Reduksjon av angrepoverflate
- Hendelsesrespons

## Studietilnærming

1. Behersk Windows-fundamentaler
2. Forstå bruker- og kontostyring
3. Studer systemadministrasjonsoppgaver
4. Lær bedriftsstyringsfeaturene
5. Gjennomgå sikkerhetspraksis

## Nøkkelbegreper å beherske

- Windows-arkitektur og komponenter
- Bruker- og kontostyring
- NTFS-tillatelser og tilgangskontroll
- GroupPolicy og domenestyring
- Windows-sikkerhetsfunksjoner
- Bedriftsdeploying-strategier
