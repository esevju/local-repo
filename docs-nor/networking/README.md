# Nettverksstudiemateriale

## Oversikt

Nettverk dekker prinsippene, protokollene og teknologiene som gjør at datamaskiner og enheter kan kommunisere. Dette inkluderer LAN/WAN-design, protokoller, sikkerhet og moderne nettverksarkitekturer.

## Emner

### Fundamentaler
- OSI og TCP/IP-modeller
- IP-adressering og subnettering
- Nettverksprotokoller (TCP, UDP, ICMP)
- DNS og DHCP
- ARP og MAC-adresser

### Nettverksdesign og arkitektur
- LAN-design og implementering
- WAN og fjerntilkobling
- Nettverkssegmentering og VLAN-er
- Trådløst nettverk (WiFi)
- Skynettverking

### Ruting og bytte
- Rutere og rutingsprotokoller
- Svitsjer og VLAN-er
- Nettverkstopologi
- Redundans og failover
- Tjenestekvalitet (QoS)

### Nettverkstjenester
- DNS (Domain Name System)
- DHCP (Dynamic Host Configuration Protocol)
- VPN (Virtual Private Networks)
- Brannmurer og tilgangskontroll
- Lastbalansering

### Sikkerhet og overvåking
- Nettverkssikkerhetsprinsippper
- Kryptering og VPN-er
- Nettverksovervåking og analyse
- Inntrengelsesdeteksjon
- DDoS-reduksjon

## Studietilnærming

1. Behersk TCP/IP-fundamentaler
2. Forstå nettverksdesignprinsippper
3. Studer ruting og bytte
4. Lær nettverkstjenestekonfigurasjon
5. Gjennomgå sikkerhetspraksis

## Nøkkelbegreper å beherske

- OSI/TCP-IP-modeller
- IP-adressering og subnetttering
- Nettverksdesign og segmentering
- Vanlige protokoller og tjenester
- Nettverkssikkerhet
- Feilsøkingsmetodikk
