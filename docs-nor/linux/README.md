# Linux studiemateriale

## Oversikt

Linux er et gratis, åpen kildekode-operativsystem som brukes mye på servere, arbeidsstasjoner og innebygde systemer. Forståelse av Linux er viktig for IT-fagfolk som administrerer variert infrastruktur.

## Emner

### Linux grunnleggende
- Linux-distribusjoner
- Installasjon og oppstartsprosess
- Filsystemhierarki (FHS)
- Kommandolinjegrunnleggende
- Bruker- og tillatelsesmodell

### Bruker- og tilgangsstyring
- Bruker- og gruppestyring
- Sudo og utvidelse av rettigheter
- Filtillatelser (rwx)
- Tilgangskontrollister (ACL)
- PAM (Pluggable Authentication Modules)

### Filsystemer og lagring
- Filsystemtyper (ext4, XFS, Btrfs)
- Diskadministrasjon og partisjonering
- Logical Volume Manager (LVM)
- Filoperasjoner og komprimering
- Sikkerhetskopi og gjenoppretting

### Systemadministrasjon
- Systeminitialisering og tjenester
- Pakkehåndtering
- Systemlogging
- Ytelsesovervåking
- Ressursstyring

### Nettverk
- Nettverkskonfigurasjon
- TCP/IP-konfigurasjon
- Nettverkstjenester (SSH, FTP, HTTP)
- Brannmur (iptables, firewalld)
- DNS- og DHCP-klientkonfigurasjon

### Sikkerhet
- Autentisering og autorisering
- Brannmur og SELinux
- SSH-konfigurasjon
- Revisjonslogging
- Inntrengelsesdeteksjon

### Scripting og automatisering
- Shell-scripting (Bash)
- Systemautomatisering
- Cron-jobber
- Systemadministrasjonsskript
- Konfigurasjonsadministrasjon

## Studietilnærming

1. Lær Linux-fundamentaler og kommandolinje
2. Behersk bruker- og tillatelsesstyringsoppgaver
3. Forstå filsystemer og lagring
4. Studer systemadministrasjon
5. Lær nettverk og sikkerhet
6. Øv scripting og automatisering

## Nøkkelbegreper å beherska

- Linux-filsystemhierarki
- Bruker-, gruppe- og tillatelsemodell
- Kommandolinjeverktøy og hjelpeprogrammer
- Pakkehåndtering
- Systemtjenester og prosesser
- Nettverkskonfigurasjon
- Sikkerhetspraksis
- Shell-scripting
