# Windows Server studiemateriale

## Oversikt

Windows Server er operativsystemet i bedriftsgrad som driver datasentre og leverer kjerne katalog-, identitets- og infrastrukturtjenester. Dette inkluderer Active Directory, fildeling, utskriftstjenester og applikasjonshosting.

## Emner

### Windows Server grunnleggende
- Server-utgaver og funksjoner
- Installasjon og konfigurasjon
- Serverroller og funksjoner
- Server Manager og administrasjon
- PowerShell for automatisering

### Active Directory og identitetstjenester
- Active Directory-struktur
- Organisasjonsenheter (OUs)
- Brukere og kontoer
- Sikkerhetsgrupper og distribusjonsgrupper
- GroupPolicy (GPO)

### Bruker- og kontostyring
- Opprett og administrer brukerkontoer
- Kontoretningslinjer og sikkerhet
- Passordretningslinjer
- Tillatelsesdelegering
- Kontolåsing og revisjon

### Gruppe- og tilgangsstyring
- Sikkerhetsgrupper
- Distribusjonsgrupper
- Gruppedeltakelse og nesting
- Tilgangskontroll og tillatelser
- Delegering av administrasjon

### Lagring og filtjenester
- Filtjenesterrolle
- NTFS-tillatelser
- Fildeling (SMB)
- Lagringsplass
- Sikkerhetskopi og katastrofetilbakestilling

### Nettverk og kommunikasjonstjenester
- DHCP-server
- DNS-server
- Ruting og fjerntilgang
- VPN-tjenester
- Nettverkstilgangsbeskyttelse

### Sikkerhet og overholdelse
- Sikkerhetsretningslinjer
- Revisjon og logging
- BitLocker og kryptering
- Windows Defender for Server
- Sikkerhetsbasislinjer
- Overholdelseskrav

## Studietilnærming

1. Behersk Windows Server-fundamentaler
2. Forstå Active Directory-arkitektur
3. Studer organisasjonsstruktur (OUs, grupper)
4. Lær bruker- og kontostyring
5. Utforsk nettverks- og lagringstjenester
6. Gjennomgå sikkerhetspolicy og overholdelse

## Nøkkelbegreper å beherske

- Active Directory-struktur og design
- Organisasjonsenheter og GPO
- Brukerkontoer, grupper og tillatelser
- NTFS og fildeling
- GroupPolicy-applikasjon
- Sikkerhetspolicys og tilgangskontroll
- Delegering og delegeringsmodeller
