# Microsoft 365 studiemateriale

## Oversikt

Microsoft 365 er en omfattende skybasert abonnementstjeneste som kombinerer produktivitetsapplikasjoner, skylagring og samarbeidsverktøy for enkeltpersoner, team og bedrifter.

## Emner

### Kjerneapplikasjoner
- Outlook (e-post, kalender, kontakter)
- Word (dokumentopprettelse)
- Excel (regneark og dataanalyse)
- PowerPoint (presentasjoner)
- OneNote (notatblokk)

### Samarbeid og kommunikasjon
- Microsoft Teams (meldinger, møter, samarbeid)
- SharePoint (dokumenthåndtering og teamsites)
- OneDrive (personlig skylagring)

### Bedriftsfunksjoner
- Exchange Online (e-post og samarbeid)
- Lisenseringsmodeller
- Sikkerhet og overholdelse
- Admin og administrasjon

## Studietilnærming

1. Start med en oversikt over hva Microsoft 365 er
2. Studer individuelle applikasjoner
3. Forstå samarbeids- og delingsfunksjoner
4. Gjennomgå bedriftsstyring og lisensiering
5. Øv bruk av hver tjeneste

## Nøkkelbegreper å beherske

- Skybasert produktivitet
- Samarbeid på tvers av team
- Datasikkerhet og overholdelse
- Integrasjon mellom tjenester
- Lisensiering og kostnadsoptimalisering
