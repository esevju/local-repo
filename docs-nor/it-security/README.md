# IT-sikkerhet studiemateriale

## Oversikt

IT-sikkerhet omfatter prinsippene, praksisen og teknologiene som brukes til å beskytte systemer, nettverk og data mot uautorisert tilgang, endring og ødeleggelse. Dette inkluderer forebyggende, oppdagende og reaktive kontroller.

## Emner

### Sikkerhetsfundamenter
- CIA-triade (Konfidensialitet, integritet, tilgjengelighet)
- Trusler og sårbarheter
- Risikovurdering og administrasjon
- Sikkerheitsrammer (NIST, ISO 27001, CIS)
- Sikkerhetspolicys og standarder

### Fysisk sikkerhet
- Adgangskontrollsystemer
- Videoovervåking og tilsyn
- Datasenterikkerhet
- Enhetssikkerhet
- Miljøkontroller

### Programvare- og applikasjonssikkerhet
- Sikker kodingspraksis
- Sårbarhetsadministrasjon
- Oppdateringsstyring
- Antivirus og anti-malware
- Endepunktsbeskyttelse

### Nettverkssikkerhet
- Brannmurer og inntrengelsesdeteksjon
- Nettverkssegmentering
- DDoS-reduksjon
- VPN og krypterte kommunikasjoner
- Truslelsovervåking

### Webbsikkerhet
- Webbapplikasjonsbrannmurer (WAF)
- Sikre webprotokoller (HTTPS, TLS)
- Cross-site scripting (XSS)
- SQL-injeksjon og injeksjonsangrep
- Øktadministrasjon

### Identitet og tilgangskontroll
- Autentiseringsmetoder
- Multi-faktor autentisering (MFA)
- Autorisering og RBAC
- Single sign-on (SSO)
- Forebygging av rettighetsskalering

### Kryptografi
- Krypteringsalgoritmer
- Public Key Infrastructure (PKI)
- Digitale signaturer
- Hashing og integritet
- Nøkkelstyring

### Hendelsesrespons og administrasjon
- Hendelsesdeteksjon og analyse
- Responseprosedyrer
- Gjenoppretting og utbedring
- Rettslig etterforsking og etterforsking
- Gjennomgang etter hendelse

### Overholdelse og styring
- Regulatory frameworks (GDPR, HIPAA, PCI-DSS)
- Revisjon og overholdelse
- Datavernet regulering
- Sikkerhetskompetenseopplæring
- Risikoledelse

## Studietilnærming

1. Forstå sikkerhetsfundamenter
2. Studer CIA-triaden og trussellandskapet
3. Lær fysiske sikkerhetskontroller
4. Behersk programvare- og nettverkssikkerhet
5. Forstå kryptografgrunnleggende
6. Studer prosedyrer for hendelsesrespons
7. Gjennomgå overholdelseskrav

## Nøkkelbegreper å beherska

- Sikkerhetsprinsippper og rammer
- Trusselidentifikasjon og risikovurdering
- Defense-in-depth-strategi
- Kryptering og nøkkelstyring
- Tilgangskontroll og autentisering
- Nettverk- og webbsikkerhet
- Prosedyrer for hendelsesrespons
- Overholdelse og regulatory requirements
