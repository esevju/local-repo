# Datamaskinhardware studiemateriale

## Oversikt

Datamaskinhardware omfatter de fysiske komponentene som utgjør datamaskinenheter, fra individuelle prosessorer til komplette systemer. Forståelse av hardware er viktig for IT-fagfolk som arbeider med distribusjon, vedlikehold og ytelsesoptimalisering.

## Emner

### Kjernkomponenter
- Prosessorer (CPU)
- Minne (RAM)
- Lagring (HDD, SSD)
- Hovedkort
- Strømforsyninger
- Kjølesystemer

### Perifer og tilkobling
- Grafikkort (GPU)
- Nettverksgrensesnitt
- USB og tilkoblingsstandarder
- Inn- og utgangsenhet
- Skjermer og monitorer

### Systemarkitektur
- Stasjonære systemer
- Serversystemer
- Bærbar og mobile enheter
- Spesialiserte systemer
- Formfaktorer

### Ytelse og spesifikasjoner
- Hastighets- og ytelsesmålinger
- Kapasitet og gjennomstrømning
- Strømforbruk
- Kompatibilitet og standarder
- Oppgradererbarhet

## Studietilnærming

1. Lær grunnleggende komponentfunksjoner og spesifikasjoner
2. Forstå hvordan komponenter fungerer sammen
3. Studer ytelsesmålinger og benchmarks
4. Gjennomgå ulike systemtyper og bruksområder
5. Øv på valg av hardware for spesifikke behov

## Nøkkelbegreper å beherske

- Komponentfunksjoner og spesifikasjoner
- Ytelsesmålinger
- Systemarkitektur
- Kompatibilitet og standarder
- Kost-nytte-analyse
- Kraft- og termiske betraktninger
