## How to Use

### Choose Your Language

**English learners:** Start with `docs/README.md`
```
cd docs
```

**Norwegian learners:** Start with `docs-nor/README.md`
```
cd docs-nor
```

### Structure is Identical in Both Languages

Both versions contain:
- Same topic organization
- Same assignment structure
- Same template files
- Same guidelines and references

The only difference is the language used in the content.

## Quick Start Guide

### English Version
1. Open [docs/README.md](docs/README.md)
2. Navigate to topic of interest
3. Use templates from `docs/templates/`
4. Work on assignment in `docs/assignments/word-assignment/`

### Norwegian Version
1. Open [docs-nor/README.md](docs-nor/README.md)
2. Navigate to topic of interest (in Norwegian)
